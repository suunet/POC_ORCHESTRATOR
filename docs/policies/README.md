# 規約の目次

gateflow 自身の Go のコードの規約。食い違ったときは、`docs/design.md` → このディレクトリの Git 管理する規約 → Git 管理外の規約の順に優先する。

| ファイル | 用途 | Git |
| --- | --- | --- |
| [coding.md](coding.md) | コードを書くときの決まり（標準ライブラリだけ、パッケージの分け方、エラー、テスト、コミット） | 管理する |
| `design.md` | 設計の考え方（失敗の扱い、冪等性、状態の保存、型の作り方） | 管理しない |
| `go-idioms.md` | Go の書き方の補足 | 管理しない |

Git 管理外のファイルは、手元にない場合がある。ない場合は`coding.md`と設計に従う。
