# テーブル定義書（`erd/columns/`）

テーブルごとの全カラム定義。ER図（俯瞰）が概観なら、ここは網羅。

## 方針

- **正本:** コードとDB（マイグレーション / `\d+ <table>` / `SHOW COLUMNS`）。この定義書はそこから生成する
- **段階的追加:** チケットで該当テーブルを触ったときに生成する。P3で§4の「更新対象シート」に挙げ（touchMapが候補を出す）、P5で生成して同じ作業ブランチに含める
- **ファイル名:** テーブル名そのまま（例: `loan.md`）
- **テンプレート:** [`table.md`](table.md)
- **手で書く欄:** 論理名・情報（INF）への紐付け・備考は人とAIが書く欄。再生成では消さない。推奨の検証（再生成して差分がないこと）は、物理の列（カラム名・型・キー・インデックス）だけを突き合わせる
- **論理名の推定:** AIが`information.md`（INF）や既存のユースケースから推定した欄は、人のコードレビューで確認する
- **ER図:** 俯瞰のER図は任意（MVPでは生成しない）。描く場合はMermaidの`erDiagram`
- **INDEX:** 1テーブル1行。テーブル名は定義書へリンクする

## 生成フロー

チケットの作業で関連テーブルを触ったとき:

1. `columns/{テーブル名}.md`が無ければ作成の対象（P3で§4に挙げる）
2. DBからスキーマを取得する（`\d+ {table}` / `SHOW COLUMNS FROM {table}`）
3. テンプレートに沿って記入する。論理名は`information.md`や既存のユースケースから推定する
4. 同じ作業ブランチに含める
